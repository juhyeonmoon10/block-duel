# BLOCK DUEL

축제 부스용 브라우저 온라인 FPS. 각자 크롬북(또는 아무 노트북/PC)으로 접속해서 1:1, 2:2로 붙습니다.
설치 없이 크롬 주소창에 주소만 치면 바로 플레이됩니다.

## 들어있는 것

- **온라인 대전**: 빠른 대전(자동 매칭), 방 만들기(4글자 코드), 코드로 입장, 관전
- **라운드제**: 3선승 또는 5선승, 한 팀 전멸 시 라운드 종료, 시간 초과 시 남은 체력 합으로 판정
- **무기 16종** (주무기 7, 보조 3, 근접 3, 장비 3)
  - 주무기: 돌격소총, 버스트 소총, 기관단총, 샷건, 저격총(스코프), 미니건(예열), 로켓 런처(범위 폭발·로켓점프)
  - 보조: 권총, 리볼버, 우지
  - 근접: 나이프, 카타나, 해머(넉백)
  - 장비: 수류탄, 연막탄, 구급상자
- **맵 3개**: 블록 창고, 루프탑, 큐브 아레나 (전부 Z축 대칭이라 공정)
- **라이벌 연출**: 경기 시작 VS 화면, 연승 기록, 1:1 상대 전적, 현재 왕좌(최고 연승 중인 사람), 도발(T), 한 판 더(리매치)
- **판정은 서버가**: 연사 속도, 데미지, 벽 너머 사격, 장비 개수 모두 서버에서 검증

## 실행 (축제 당일, 노트북 1대를 서버로)

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

서버 창에 이런 주소가 뜹니다.

```
이 컴퓨터:      http://localhost:3000
같은 와이파이:  http://192.168.0.23:3000
```

크롬북들은 **같은 와이파이**에 연결한 뒤 두 번째 주소로 접속하면 됩니다.

> 학교 와이파이는 기기끼리 통신을 막아두는 경우가 많습니다(AP 격리). 크롬북에서 주소가 안 열리면
> 휴대폰 핫스팟이나 공유기 하나를 부스에 두고 서버 노트북과 크롬북을 전부 거기에 연결하세요.
> 아니면 아래처럼 인터넷에 올리면 와이파이 종류와 상관없이 됩니다.

## 인터넷에 올리기 (Render 무료)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/juhyeonmoon10/block-duel)

1. 위 버튼을 누르고 GitHub 계정으로 Render에 로그인합니다.
2. Apply(배포)를 누르면 `render.yaml` 설정대로 서버가 만들어집니다.
3. 배포가 끝나면 `https://block-duel-xxxx.onrender.com` 같은 주소가 나옵니다. 크롬북에서 그 주소로 접속.

GitHub Pages는 정적 파일만 올릴 수 있어서 대전 서버가 돌아가지 않습니다. 코드는 GitHub에, 서버는 Render에 둡니다.

무료 플랜은 15분 동안 아무도 안 들어오면 잠들고, 첫 접속 때 깨어나는 데 30초~1분 걸립니다.
축제 시작 직전에 한 번 열어두세요. 연승 랭킹은 서버가 재시작되면 초기화됩니다.

## 조작

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| Space | 점프 |
| 좌클릭 / 우클릭 | 발사 / 조준 |
| R | 재장전 |
| 1 2 3 / 휠 | 주무기 / 보조 / 근접 |
| G (또는 4) | 장비 사용 (수류탄·연막 던지기, 구급상자) |
| Q | 이전 무기 |
| T → 1~6 | 도발 |
| Tab | 점수판 |
| B | 무기 변경 (라운드 사이) |
| Esc | 멈춤 |
| 죽은 뒤 A / D, V | 관전 대상 바꾸기, 전체 보기 |

크롬북 터치패드는 누른 채로 있으면 연사가 됩니다. 부스에 USB 마우스를 두면 훨씬 편합니다.

## 부스 운영 팁

- **큰 화면 관전**: 부스 TV에 연결한 노트북으로 방 코드 입력 → 관전. 플레이어를 따라가며 보여줍니다.
- **느린 크롬북**: 로비의 설정 → 화질 → 가볍게.
- **연승 왕좌**: 로비 오른쪽에 현재 최고 연승자가 계속 떠 있어서 "저 사람 이겨봐" 동기가 됩니다. 연승 상품을 걸면 효과가 좋아요.
- 랭킹 초기화: 서버 끄고 `data/leaderboard.json`, `data/rivals.json` 삭제.

## 고치고 싶을 때

| 하고 싶은 것 | 파일 |
|---|---|
| 무기 데미지·연사·탄창 등 밸런스 | `shared/weapons.js` (서버/클라이언트 동시 적용) |
| 맵 수정·추가 | `shared/maps.js` (박스 좌표만 쓰면 됨) |
| 라운드 시간, 준비 시간 | `server/room.js` 맨 위 `T` |
| 이동 속도, 점프, 중력 | `shared/physics.js` |
| 무기 모양 | `public/js/models.js` |
| 화면 디자인 | `public/css/style.css` |

## 구조

```
server/index.js    웹 서버 + Socket.IO, 방 목록, 랭킹 저장
server/room.js     방 하나의 경기 진행 (라운드, 판정, 투사체)
shared/            서버와 브라우저가 같이 쓰는 데이터 (무기, 맵, 물리)
public/js/game.js  3D 렌더링(three.js), 조작, 총기, 이펙트
public/js/main.js  로비/대기실 화면, 서버 이벤트 연결
public/js/hud.js   체력, 탄약, 킬피드 등 화면 표시
public/js/audio.js 효과음 (전부 코드로 합성, 음원 파일 없음)
```
